# Ship Salvage & Wreck Removal — сайт компании

Одностраничный корпоративный сайт: **Главная · Услуги · О нас · Контакты**.
Английский (основной) + русский (переключатель EN/RU в шапке). Тёмно-синий
минималистичный стиль, адаптивная вёрстка, SEO-разметка, логотип-якорь (SVG).

## Структура

```
index.html        — все страницы/секции (EN/RU через data-i18n)
css/style.css     — стили (тёмно-синий, адаптив)
js/main.js        — переключатель языка, меню, форма
img/
  hero.jpg        — фон главного экрана
  about.jpg       — фото секции «О нас»
  favicon.svg     — иконка сайта
```

## ⚠️ Перед публикацией: замените контакты

Сейчас стоят плейсхолдеры. Найти и заменить в **3 местах**:

| Что | Где | Значение |
|---|---|---|
| Телефон | временно убран — добавится позже | — |
| Email | `index.html` + `js/main.js` → `CONFIG.CONTACT_EMAIL` + JSON-LD | `ildus650@gmail.com` |
| Telegram-бот | `index.html` (кнопка в контактах) | добавится после создания бота |

Тексты сайта — в словаре `I18N` в `js/main.js` (блоки `en` и `ru`).
Цифры «15+ лет, 120+ проектов, 10+ стран» — примерные, поправьте под себя.

## Как работает форма

Форма отправляется без перезагрузки через бесплатный сервис **FormSubmit.co**.
Первый раз после замены email на свой:

1. Отправьте тестовое сообщение с сайта.
2. На ваш email придёт письмо от FormSubmit — нажмите кнопку активации.
3. Готово: все заявки будут приходить на этот адрес.

Если отправка не удалась (нет сети и т.п.) — форма автоматически откроет
почтовый клиент с готовым письмом (fallback на `mailto:`).

## Бесплатный хостинг (варианты)

### 0. Автоматически, скриптом (Netlify CLI)
В папке проекта лежит `deploy-netlify.sh` — публикация одной командой:
`bash deploy-netlify.sh`. Первый запуск: установит netlify-cli, откроет браузер
для входа в Netlify (кнопка Authorize), затем опубликует сайт на
`https://<имя>.netlify.app`. Повторные запуски обновляют сайт.

Также есть готовый архив `shipsalvage-site.zip` — его можно распаковать
и перетащить папку в Netlify Drop (вариант 1).

### 1. Netlify Drop — быстрее всего, без регистрации
1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите **всю папку сайта** (index.html + css + js + img) в окно браузера.
3. Через ~10 секунд получите ссылку вида `https://name.netlify.app` — сайт уже в интернете.

### 2. GitHub Pages
1. Создайте репозиторий на GitHub и загрузите в него файлы сайта.
2. `Settings → Pages → Source: Deploy from a branch → main → / (root) → Save`.
3. Через 1–2 минуты сайт будет на `https://username.github.io/repo/`.

### 3. Vercel
1. [vercel.com](https://vercel.com) → New Project → импортируйте папку (или репозиторий).
2. Настройки по умолчанию подходят, дополнительно ничего настраивать не нужно.

## Что внутри (кратко)

- **EN/RU**: кнопки EN/RU в шапке, выбор запоминается в браузере; язык
  определяется автоматически по настройкам посетителя.
- **SEO**: title, meta description, Open Graph, разметка JSON-LD
  (ProfessionalService), семантический HTML, alt-тексты, robots.
- **Услуги**: 4 блока (подъём до 3 000 т · подводная резка · откачка воды ·
  утилизация металла) с SVG-иконками.
- **Адаптив**: меню-бургер на телефонах, сетки перестраиваются под любой экран.
